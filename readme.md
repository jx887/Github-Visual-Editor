# GitHub Markdown Visual Editor

A WYSIWYG editor for `.md` files on github.com. It's just a bookmark. No extensions.

**Install:** go to **https://md.fatpug.io/** and drag the **✨ GH Editor** button to your bookmarks bar.
Then open any `.md` file on GitHub and click the bookmark.

## Save as bookmark

Or add a bookmark by hand: name it **GH Editor** and paste this as its URL.
